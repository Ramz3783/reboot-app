# REBOOT — Android приложение (Kotlin + Jetpack Compose)

Настоящее нативное Android-приложение, написанное на Kotlin с использованием Jetpack Compose.
Никакого HTML/WebView — это компилируемый Android Studio проект.

## Что внутри

- **Экраны**: Splash, Вход/Регистрация, Онбординг (3 шага), Главная (Dashboard с XP/уровнями),
  Планы, AI-наставник (5 режимов: Мотиватор/Стратег/Провокатор/Турбо/Друг), Голосовой AI,
  Прогресс (график), Профиль, Достижения, Привычки, Создание задачи, Фокус-режим (таймер),
  Настройки, PRO.
- **Хранение данных**: Jetpack DataStore — пользователь, задачи, привычки, XP/уровень/streak,
  история чатов с AI сохраняются локально на устройстве и переживают перезапуск приложения.
- **AI**: прямая интеграция с Groq API (chat completions + Whisper speech-to-text) прямо из
  приложения — без своего backend-сервера.

## Как собрать APK

1. Установи [Android Studio](https://developer.android.com/studio) (последняя стабильная версия).
2. Открой эту папку как проект (`File → Open` → выбери папку `reboot_app`).
3. Дай Gradle синхронизироваться (первый раз скачает зависимости — нужен интернет).
4. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
5. Готовый APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

Либо через терминal в папке проекта:
```
./gradlew assembleDebug
```
(на Windows: `gradlew.bat assembleDebug`)

Gradle wrapper jar-файл не включён в архив (бинарник) — при первом открытии в Android Studio
среда сама предложит скачать нужную версию Gradle, либо выполни `gradle wrapper` вручную, если
у тебя установлен Gradle.

## Как подключить AI (Groq)

1. Зарегистрируйся на https://console.groq.com и создай API-ключ (бесплатный тариф есть).
2. Открой приложение → Профиль → Настройки → вставь ключ в поле "Groq AI" → Сохранить.
3. После этого AI-наставник и голосовой AI начнут отвечать по-настоящему.

Ключ хранится только локально на устройстве (DataStore), никуда кроме api.groq.com не уходит.

## Важно понимать про масштаб

Это рабочий, самостоятельный каркас приложения, реализующий все ключевые экраны и механики из
макетов: авторизация, онбординг, геймификация (XP/уровни/streak/монеты), задачи, привычки, планы,
AI-чат с несколькими личностями, голосовой AI, фокус-таймер, достижения, настройки, PRO-экран.

Оригинальное ТЗ на ~8000 строк описывает полноценный продакшн-продукт с бэкендом на
FastAPI/PostgreSQL, платежами, push-уведомлениями с сервера, модерацией и т.д. — это уже
отдельный проект уровня "команда на несколько недель/месяцев", а не то, что можно упаковать в
один zip. Этот каркас — прочная основа, которую можно дальше наращивать экран за экраном.

## Иконка

Иконка сгенерирована в неоновом стиле (фиолетово-бирюзовый градиент, символ power/reboot),
уже разложена по всем плотностям (mipmap-mdpi…xxxhdpi) и подключена в манифесте.
