# Полный scope REBOOT

## Core
Регистрация, вход, onboarding, профиль, привычки, проблемы, цели, персонализация.

## RPG
XP, уровни, streak, daily quest, achievements, категории, квесты и безопасные челленджи.

## 5 вкладок
Дом, Планы, ИИ, Прогресс, Я.

## Планирование
Тренировки, саморазвитие, карьера, психология, здоровье, свободная цель.

## AI
Друг, Тренер, Провокатор, Мудрец, Турбо.
Groq chat + генерация JSON-планов.
История последних сообщений.
Голосовой ввод Android и TTS-ready.

## Progress
Календарь, выполнение задач, streak, достижения, статистика привычек, AI history.

## Дополнительные экраны
Режим Тишины 5-4-3-2-1, трекер привычек, дневник, турнир, referral, subscription.

## Design
Glass-like dark cards, purple/cyan/pink gradients, subtle motion, custom vector icons.
Lucide/Material vector assets вместо эмодзи.

## Безопасность
Никаких секретов в APK. Backend proxy. Rate limits и validation обязательны для production.
